# Morpheus Benchmark

Morpheus is a PLDI 2017 benchmark suite for example-driven synthesis of table transformation programs. 
Each benchmark contains one input-output example over one or more tables.

Derived and using the setup from Neo (Feng et al., 2018), this benchmark is comprised of 72 problems.

See
> Feng, Y., Martins, R., Bastani, O., & Dillig, I. (2018). Program synthesis using conflict-driven learning. ACM SIGPLAN Notices, 53(4), 420-435.

> https://utopia-group.github.io/morpheus/
